# AI駆動型開発（AI-Driven Development）総合学習ガイド＆2,500語辞典

AI駆動型開発の全体像を **「自然な物語・対話で学ぶ25話のストーリーガイド」** と **「体系的に引ける2,500語の用語辞典」** の2層構造でまとめたナレッジベースです。

---

## おすすめの学習ロードマップ

1. **ステップ1：入門5部作（各ジャンルの第1話）を通読する**
   - `01` → `02` → `03` → `04` → `05` の順に `story_01` を読むと、新機能「スマート請求管理」の企画から実装・テスト・運用・組織展開までの一連の流れで全体像がつかめます。
2. **ステップ2：気になる領域の第2話〜第5話で深掘りする**
   - 各話は **① 現場のストーリー＆対話（4シーン） → ② DUO式・高密度復習フレーズ（5本） → ③ 登場キーワード逆引きリスト → ④ 現場で活かす深掘り解説＆ミニクイズ** の4部構成です。
3. **ステップ3：500語辞典（各フォルダの `README.md`）で詳細を引く**
   - ストーリー内の太字キーワードは、各ジャンル `README.md` の番号（`#1`〜`#500`）に対応しています。

### ストーリーの主な登場人物
- **サトウ**: テックリード。設計・アーキテクチャ・AI統制の勘所を現場目線でガイドする。
- **ミサキ**: 入社2年目のエンジニア。最新のAIツールを積極的に試しながら、疑問や現場のリアルな壁を言語化する。
- **ユイ**: プロダクトマネージャー（PM）。ビジネス価値・仕様・優先度・顧客体験の視点からプロジェクトを牽引する。
